# Poolside Agent Harness Cover Letter

Dear Poolside team,

I am applying for the Member of Engineering, Agent Harness role because it is almost exactly the problem space I have been living in at Cosine: building the core framework, runtime, tools, and secure execution substrate for AI coding agents.

At Cosine, I am CTO and lead product and engineering for an applied AI lab focused on software engineering agents. A large part of my work has been building the harness itself, not just product around someone else's agent loop. I designed and shipped our Go runtime for streaming tool calls, checkpoints, deterministic replay, memory writes, MCP and LSP integration, subagents, file locks, repository search, browser use, and structured rollout logs. That same runtime now supports CLI, desktop, VS Code/WebAssembly, API-server sessions, and remote worker pods.

I also led the build-out of our sandboxing and remote execution stack from 2024 onward: Kubernetes-scheduled agents, gVisor/runsc isolation, ephemeral per-session environments, network-policy boundaries, and secure shell/tool access for LLM-controlled coding work. That infrastructure is what lets agents operate on real codebases with enough isolation, observability, and repeatability to be useful in serious enterprise environments.

What makes Poolside especially compelling is that you are tackling the same category at frontier-model scale: coding agents, secure enterprise deployment, and the harness layer where research capability becomes reliable product behavior. The role description maps directly onto the work I have already done: core agent framework, supporting tools, isolated runtimes, collaboration with research and product, performance, reliability, and developer experience.

I would bring unusually relevant experience because I have already had to make these tradeoffs in production. I have seen where agent systems break down, where tool abstractions leak, how hard replay and debugging become once agents are long-running, why filesystem and repository operations dominate perceived latency, and why secure enterprise deployment cannot be treated as an afterthought.

Poolside's mission of accelerating software development through agentic systems is the mission I have been working on directly. I would be excited to help build the harness layer that makes those systems more capable, reliable, and usable for real developers.

Best,
